ⓘ Penjelasan Program

Program ini menggunakan Algoritma Linear Search untuk mencari 3 nilai terbesar dari data siswa, kemudian menampilkannya sebagai peringkat 1, 2, dan 3.

Data siswa dimasukkan melalui form. Program memeriksa nilai satu per satu dari array, menemukan nilai terbesar, menandai data tersebut, lalu mengulangi proses sampai diperoleh tiga nilai terbesar.

⚙️ Algoritma Linear Search

Linear Search adalah metode pencarian yang memeriksa data satu per satu dari awal sampai akhir sampai data yang dibutuhkan ditemukan.

Langkah-langkah

  1. Periksa seluruh data siswa satu per satu.
  2. Cari nilai terbesar pertama.
  3. Simpan posisi siswa yang memiliki nilai terbesar.
  4. Tandai data tersebut agar tidak dipilih kembali.
  5. Ulangi pencarian untuk mendapatkan nilai terbesar kedua.
  6. Ulangi kembali untuk mendapatkan nilai terbesar ketiga.
  7. Tampilkan tiga siswa sebagai peringkat 1, 2, dan 3.

🧪 Contoh Proses

Data nilai: 80, 95, 70, 88, 100, 75, 92

  • Linear Search pertama → 100
  • Linear Search kedua → 95
  • Linear Search ketiga → 92

Hasil: Peringkat 1 = 100, Peringkat 2 = 95, Peringkat 3 = 92.
