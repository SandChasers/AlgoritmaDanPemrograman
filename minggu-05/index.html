Definisi Algoritma Pencarian

Linear Search (Pencarian Sekuensial)

Metode pencarian paling mendasar yang bekerja dengan mengecek setiap elemen di dalam array satu per satu dari indeks pertama (0) hingga indeks terakhir (n-1).

  • Analogi Maba: Seperti mencari file tugas di folder yang berantakan dengan mengecek isi file satu per satu.
  • Kelebihan: Praktis dan fleksibel, tidak membutuhkan syarat data harus terurut (bisa untuk unsorted array).
  • Kekurangan: Lambat untuk dataset berukuran besar karena kompleksitas waktunya O(n).

Binary Search (Pencarian Biner)

Metode pencarian efisien berbasis pendekatan Divide and Conquer. Algoritma ini membagi area pencarian menjadi dua bagian secara berulang dengan membandingkan nilai target terhadap elemen tengah (mid).

  • Analogi Smt 3: Seperti mencari kata di kamus terjemahan, langsung buka halaman tengah lalu putuskan cari ke sebelah kiri atau kanan.
  • Kelebihan: Sangat cepat untuk data berukuran besar dengan kompleksitas waktu logaritmis O(log n).
  • Kekurangan: Wajib memenuhi syarat utama, yaitu data harus sudah terurut (sorted array).

Perbedaan Linear Search vs Binary Search

Kategori Perbandingan Linear Search Binary Search
Prinsip Kerja Memeriksa setiap elemen satu per satu secara berurutan dari awal sampai akhir. Membagi area pencarian menjadi dua bagian secara berulang berdasarkan nilai tengah.
Syarat Data Data bisa berurutan maupun acak (tidak perlu diurutkan). Data wajib terurut (sorted) terlebih dahulu.
Kompleksitas Waktu (Worst Case) O(n) - Jumlah langkah sebanding dengan jumlah data. O(log n) - Jumlah langkah bertambah jauh lebih lambat dibanding data.
Kecepatan Lambat untuk data berukuran besar. Sangat cepat untuk data berukuran besar.
Penggunaan Terbaik Data kecil atau data yang tidak terurut. Data jumlah besar yang sudah terurut.
