Penjelasan Program

Program ini digunakan untuk mengurutkan nilai ujian mahasiswa dengan algoritma Bubble Sort. Data mahasiswa disimpan dalam sebuah array yang berisi nama dan nilai ujian.

Bagaimana Bubble Sort Bekerja?

  1. Program membandingkan nilai dua mahasiswa yang posisinya bersebelahan.
  2. Jika urutannya belum sesuai pilihan, kedua data ditukar.
  3. Proses perbandingan dan pertukaran diulang sampai data terurut.
  4. Data yang sudah terurut kemudian ditampilkan kembali pada tabel.

Pilihan Pengurutan

  • Ascending: nilai diurutkan dari yang terkecil ke terbesar.
  • Descending: nilai diurutkan dari yang terbesar ke terkecil.

Fungsi Tombol

  • Urutkan dengan Bubble Sort: mengurutkan data berdasarkan pilihan.
  • Reset Data: mengembalikan daftar ke urutan awal.

Catatan: Nama dan nilai yang ditampilkan merupakan data contoh. Data dapat diubah pada array initialStudents di file script.js.
